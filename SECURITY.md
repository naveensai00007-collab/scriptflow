# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Local-First Data Guarantee

ScriptFlow operates on a **100% local-first** architecture.
- Screenplays, character bios, call sheets, and revisions are stored solely within your local browser's IndexedDB and localStorage sandbox.
- No screenplay text, character dialogue, or creative drafts are ever transmitted to external cloud servers or used to train third-party AI models without explicit user configuration.

## Reporting a Vulnerability

If you discover a security issue or vulnerability in ScriptFlow, please report it privately to the author **Naveen Sai**. We will acknowledge receipt within 48 hours and work expeditiously on a patch.
